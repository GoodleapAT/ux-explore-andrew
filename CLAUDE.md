# Read this first

Read **`START-HERE.md`** before doing anything in this repository. It carries the protocol, the index,
and the rule for what is global and what belongs to a project.

Two things you must not skip.

**Read `standards/` before building anything.** Short files, one per topic. They exist because the
same corrections were being made session after session. Building a mockup without reading
`mockup-density.md` and `ui-composition.md` will produce the wrong thing.

**Write back before the session ends.** Two questions, always both: what did we learn about the
problem, and what did we learn about how to work on it. The second goes into `standards/`. If Andrew
corrected something and no standard changed, the session lost work. If you cannot write to files, end
by producing a paste-able write-back block instead; `START-HERE.md` says what one looks like.

House rules, in brief: no em dashes, short replies, plain language and no file paths in conversation,
lead with the decision and the trade-off, and **ask before building or rebuilding any artifact, every
time**. The full versions are in `standards/working-voice.md`.
