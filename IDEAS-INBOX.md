# Ideas inbox

**Raw capture, for every project. Three fields, no thinking required.**

> **Who may write to this file:** anyone and any surface. **Append only.** Add to the bottom. Never
> edit an existing line, never reorder, never tidy, never delete. When an idea is promoted into a project's
> `IDEAS-CATALOGUE.md`, leave the line here and add its new ID in square brackets at the end.
>
> **This file is global on purpose.** Deciding which project an idea belongs to is a routing decision,
> and routing at capture time is friction. Routing happens at promotion. Name the project in the
> origin field if you know it.
>
> **Format:** `- **date** | one sentence | where it came from`
>
> One sentence means one sentence. If it needs a paragraph it is not a capture, it is a record, and
> it belongs in the catalogue. If you cannot tell whether it is a problem or a solution, write it
> anyway. Sorting that out is the catalogue's job.
