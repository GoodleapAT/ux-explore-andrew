# ux-explore-andrew

Design and modelling working memory. Andrew Thompson, UX / Product Design, GoodLeap. Private.

**If you are a person:** open `START-HERE.md`.

**If you are an AI agent:** read `START-HERE.md` before doing anything else. It carries the protocol,
the index, and the rule for what is global and what belongs to a project. Read `standards/` before
building anything, and write back before the session ends.

## What is here

- **Root** holds what is true across every project: the protocol, global sources, the idea inbox,
  the process decision log, the standards, extracted reference material, and the standards rendered
  for surfaces that cannot read this repository.
- **A folder per project** holds that project's overview, sources, decisions, idea catalogue and
  vocabulary, then a folder per thread of work inside it.

Today there is one live project, **Upgrade to Pros**, taking GoodLeap's contractor tooling from
payments only into selling and operations.

Standalone hosted prototypes live here too, in `prototypes/`, because this repository is what they
are served from.

## What is not here

Any team's authoritative record, which lives in that team's own repository. Nothing in this repository
is authoritative for anyone but Andrew.
