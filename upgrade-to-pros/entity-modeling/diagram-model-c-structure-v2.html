The project is the container

One customer, holding properties, opportunities and a customer-level record, and a mandatory project that contains the priced offer, the work and the money. Nothing inside the project is nested under anything but the project.

Reading the links Nested = contains Labelled arrow = produces Dashed, no head = references, owns nothing Stacked = one or more

Containment is the only structural claim here: the project holds the proposal, the jobs and the money, and nothing inside it is nested under anything else. The single arrow marks the one place where one object produces another. Properties and opportunities are referenced rather than owned, which is what lets a declined opportunity survive. The project and the job each carry their own configurable pipeline, drawn the same way at both levels.
